# pair-wise-yy-59 法律文件披露、去密与发布质控工作台

用于诉讼披露批次中的区域去密、原页/发布页双人复核、文档标签和发布门禁。PDF.js 真实渲染示例文档，去密区域可绘制、确认并持久化到本地草稿。

## 授权依据模型

文档密级、去密区域、复核结论和发布批次共用一条**授权依据**（AuthBasis）：

- **依据失效 cascade**：密级或区域变化后，相关复核失效，待导出批次退回等待，其他文档照旧。
- **权限矩阵**：查看、修改、导出均按角色 × 密级校验，权限不足时拒绝并写入审计日志。
- **双人并发复核**：先提交者占用依据（复核已接受），后到者的区域和理由进入待裁决账，不能覆盖已接受内容。
- **检查点导出**：导出失败后从检查点重试，同一文档不会在批次里重复。
- **批次快照隔离**：旧批次缺少密级快照时先隔离待复核，不能按今天的密级放行。
